# Retired combat generations

The disciple/warden combat prototype was abandoned before the current Black Mist experience. Its unused application code, exported duplicates, Blender intermediates, review images and verification scripts were removed on 2026-10-08.

`manifest.json` is retained as historical provenance for the two model generations and two rigging tasks, which consumed 150 credits. Its paths describe the retired exports, not current runtime assets.

The paid original model and rig downloads remain locally in the ignored `sources/` and `tripo-out/` directories. They are not copied into the build or submitted to Git. No generation was repeated during cleanup.

Active creature assets, source receipts and build instructions are documented in [the Black Mist pipeline](../../asset-pipeline/black-mist/README.md). Current gameplay lives in `src/world/blackMist/`.
